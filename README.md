# Homebrew Tap for Pranata

Official Homebrew Tap for [Pranata](https://pranata.dev) — API Client & Collaboration Platform.

## Installation

```bash
brew tap agungtp22/tap
brew install --cask pranata
```

## Update

```bash
brew upgrade --cask pranata
```

## Uninstall

```bash
brew uninstall --cask pranata
```
